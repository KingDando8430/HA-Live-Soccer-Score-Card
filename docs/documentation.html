Live Soccer Score Card

A single-entity Lovelace card for live football scores. Built for Multiscrape sensors, with flags, kickoff/live/full-time status, and an entity suggestion for FIFA World Cup sensors.

Adding the card to a dashboard

The card is a plain JavaScript module — no build step, no dependencies.

  1. Copy live-soccer-score-card.js to <config>/www/live-soccer-score-card.js.
  2. Go to Settings → Dashboards, open the three-dot menu, and select Resources.
  3. Select Add resource. Set the URL to /local/live-soccer-score-card.js and the type to JavaScript module.
  4. Edit a dashboard, select Add card, and either pick a matching Multiscrape entity (see Entity suggestions) or search for Live Soccer Score.

If you update the file later and the dashboard doesn't pick up the change, browsers cache JavaScript resources aggressively. Bump the resource URL to /local/live-soccer-score-card.js?v=2 or hard-refresh.

YAML configuration

All options can also be set through the visual editor.

entity string Required

Entity ID of a Multiscrape sensor exposing team_1, team_2, ongoing, and score data. The visual editor only lists entities from the Multiscrape integration.

title string Optional

Overrides the label shown at the top of the card.

Default: the entity's friendly_name attribute.

subtitle string Optional

Text appended after the title, e.g. Quarterfinal. The entity has no round/stage attribute of its own, so this is set per-card.

Team names are always abbreviated to 3 letters — there is no long-name display option.

Sizing (Sections view)

The card defaults to columns: 12 (full width) and rows: auto (height follows content). Override per-instance if needed:

type: custom:live-soccer-score-card
entity: sensor.your_multiscrape_entity
grid_options:
  columns: 12
  rows: auto

Example

type: custom:live-soccer-score-card
entity: sensor.your_multiscrape_entity
subtitle: Quarterfinal

Entity suggestions

When you add a card by picking an entity first (rather than picking a card type), Home Assistant can suggest this card automatically.

The card is suggested when an entity's ID contains fifa or world_cup and the entity comes from the Multiscrape integration. Both conditions must match — a Multiscrape entity without one of those words, or a non-Multiscrape entity with one, won't trigger it.

Requires Home Assistant 2026.6 or newer. On older versions this feature is silently skipped — nothing breaks, the suggestion just won't appear.

Flags

Team badges show a national flag when the team name resolves to one, loaded directly by the browser from the flag-icons CDN as a square SVG — no images are bundled with the card. If a name doesn't resolve (unmapped country, or a club name — clubs don't have national flags), the badge falls back to a 3-letter text badge instead of a broken image.

The lookup table covers national teams across all six confederations:

ConfederationCoverage
UEFAAll major European national teams, plus England, Scotland, Wales and Northern Ireland as separate codes (gb-eng, gb-sct, gb-wls, gb-nir)
CONMEBOLAll 10 South American federations
CONCACAFCommon North/Central American and Caribbean teams
AFCCommon Asian teams
CAFCommon African teams
OFCCommon Oceanian teams

Not every FIFA member is included. To add one, open live-soccer-score-card.js and add a line to the COUNTRY_FLAG_CODES object near the top of the file — the key is the lowercased team name, the value is the flag-icons code (usually the 2-letter ISO code, e.g. es for Spain; some regions use extended codes like gb-eng).
